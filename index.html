About this map

Source: the Washington County Sheriff's Office weekly media incident summaries (MediaReports/RMS), 37 weekly files filtered to rows with city = HUGO and a 2026 timestamp. All Hugo calls are handled by the Sheriff's Office, which is Hugo's contracted police service.

Positions are approximate by design. The county publishes addresses at block level ("5XXX 157th St N") or as intersections. Each dot is placed on the named street using Washington County's house-number grid (about 1,000 numbers per mile, calibrated against OpenStreetMap address points), then nudged a few dozen meters so overlapping calls stay visible. Intersections are computed from OpenStreetMap centerlines. 64 incidents list no usable address and are not shown.

Severity tiers are an editorial grouping of the county's 120 event labels, not an official ranking. Base map data © OpenStreetMap contributors (ODbL).
